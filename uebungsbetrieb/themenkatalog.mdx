Im Themenkatalog sammeln Sie Vorlagen für Übungen. Wenn Sie später eine Übung im [Übungsplan](/uebungsbetrieb/uebungsplan) anlegen, wählen Sie einfach ein Thema aus. Die Angaben können Sie dort noch anpassen.

<Info>
  Wo finden Sie das? Im Menü links unter **Übungsbetrieb › Themenkatalog**.
</Info>

## Ein Thema anlegen

1. Wählen Sie oben die **Abteilung**.
2. Klicken Sie auf **Thema anlegen**.
3. Tragen Sie ein:
   - **Katalognr.**: eine eigene Nummer, zum Beispiel aus dem Ausbildungsrahmenplan,
   - **Bezeichnung**: das Thema, zum Beispiel „Technische Hilfe – Verkehrsunfall“,
   - **Ort**: zum Beispiel „Gerätehaus“,
   - **Übungsart**: zum Beispiel Theorie oder Praxis,
   - **Dauer (Std:Min)**.
4. Schalten Sie **Pflichttermin** ein, wenn alle teilnehmen müssen.
5. Schalten Sie **Zählt zu den Pflichtstunden** aus, wenn das Thema nicht zählen soll.
6. Klicken Sie auf **Speichern** oder **Speichern und neu**.

## Themen suchen und bearbeiten

Mit dem Feld **Suche** finden Sie Themen nach Bezeichnung oder Katalognummer. Mit dem **Stift** bearbeiten, mit dem **Papierkorb** löschen Sie ein Thema. Bereits geplante Übungen bleiben beim Löschen erhalten.

Übungsarten legen Sie unter [Übungsarten](/einstellungen/wehr/uebungsarten) an.
