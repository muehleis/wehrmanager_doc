Mit der Personalliste stellen Sie sich jede Liste zusammen, die Sie brauchen. Zum Beispiel eine Telefonliste der Einsatzabteilung, alle Atemschutzgeräteträger oder alle Mitglieder über 60 Jahre.

<Info>
  Wo finden Sie das? Im Menü links unter **Auswertungen › Personalliste**. Sie brauchen dafür das Recht **Personallisten**.
</Info>

## Die Liste zusammenstellen

Die Einstellungen sind in vier aufklappbare Bereiche gegliedert. Jede Änderung zeigt sofort das Ergebnis.

### Stichtag und Mitgliedschaft

- **Stichtag**: Der Tag, auf den sich die Liste bezieht. Leer bedeutet heute. So können Sie zum Beispiel sehen, wer am 31.12. des Vorjahres Mitglied war.
- **Mitgliedschaft am Stichtag**: **Aktuelle Mitglieder**, **Aktuelle und ehemalige Mitglieder**, **Nur ehemalige Mitglieder** oder **Ohne Mitgliedschaft**.
- **In den Abteilungen**: Eine oder mehrere Abteilungen.
- **Verstorbene einbeziehen**: Auch verstorbene Personen anzeigen.

### Person

- **Anrede**, **Alter von … bis**, **Familienstand** und **Führerschein**.
- **Tags**: Personen, die mindestens einen der gewählten Tags haben.
- **Nur wenn ausgefüllt** und **Nur wenn leer**: zum Beispiel alle Personen, bei denen die E-Mail-Adresse fehlt.

### Dienstgrad, Funktion, Ausbildung

Filtern Sie nach **Dienstgrad am Stichtag**, **Funktion am Stichtag**, erfolgreicher **Ausbildung**, **Abzeichen** oder **Übungsgruppe am Stichtag**.

### Spalten und Sortierung

Wählen Sie die **Sortierung** (Name, Geburtsdatum, Ort und Straße oder interne Nummer) und haken Sie die **Spalten** an, die in der Liste stehen sollen. Zur Auswahl stehen zum Beispiel Anschrift, Telefon, E-Mail, Geburtsdatum, Alter, Eintritt, Mitgliedsjahre, Führerschein, letzte Führerscheinkontrolle, Tags und IBAN.

Mit **Alles zurücksetzen** beginnen Sie von vorn.

## Die Liste ausgeben

Über der Tabelle steht, wie viele Personen gefunden wurden. Danach haben Sie diese Möglichkeiten:

| Schaltfläche | Ergebnis |
| --- | --- |
| **Drucken** | Eine druckfertige Liste. |
| **CSV / Excel** | Eine Datei, die Sie mit Excel öffnen können. |
| **Serienbrief** | Ein Brief für jede Person der Liste, aus einer Briefvorlage. Vorlagen legen Sie unter [Briefe](/einstellungen/wehr/briefe) an. |

## Listen speichern

Brauchen Sie eine Liste öfter, speichern Sie sie:

1. Klicken Sie auf **Speichern**.
2. Geben Sie eine **Bezeichnung** ein. Unter einem vorhandenen Namen wird die Liste überschrieben.
3. Schalten Sie **Für alle Benutzer der Wehr freigeben** ein, wenn auch andere die Liste nutzen sollen.

Unter **Gespeicherte Listen** rufen Sie Ihre Listen wieder auf. Dort können Sie eigene Listen auch löschen.
