In der Personenliste finden Sie alle Personen Ihrer Wehr. Von hier aus öffnen Sie eine Person, um ihre Daten zu sehen oder zu ändern.

<Info>
  Wo finden Sie das? Im Menü links unter **Personen**. Schneller geht es mit dem Feld **Person suchen** oben in der Leiste.
</Info>

## Eine Person finden

1. Tippen Sie in das Feld **Schnellsuche** einen Namen, einen Ort oder eine Nummer.
2. Die Liste passt sich sofort an. Sie müssen nicht auf „Suchen“ klicken.
3. Klicken Sie auf den Namen, um die Person zu öffnen.

## Die Filter

Mit den Filtern grenzen Sie die Liste weiter ein:

| Filter | Wofür? |
| --- | --- |
| **Nachname**, **Vorname** | Nur Personen mit diesem Namen. |
| **PLZ**, **Ort** | Nur Personen aus diesem Ort. |
| **Geburtsdatum** | Tag (TT), Monat (MM) und Jahr (JJJJ) einzeln. Sie können auch nur einen Teil angeben, zum Beispiel nur den Monat, um alle Geburtstage im Mai zu finden. |
| **Abteilung** | Nur Mitglieder dieser Abteilung. |
| **Mitgliedschaft** | **Aktuelle Mitglieder**, **Ohne aktuelle Mitgliedschaft** (zum Beispiel ausgetretene Personen) oder **Alle**. |

Mit **Filter zurücksetzen** leeren Sie alle Filter auf einmal.

## Was die Liste zeigt

Für jede Person sehen Sie **Name**, **Geburtsdatum** mit Alter, **Anschrift** und die **Abteilungen**, zu denen sie gehört. Bei verstorbenen Personen steht ein Kreuz (†) hinter dem Namen.

<Tip>
  Sie brauchen eine Liste zum Drucken oder für Excel? Dafür gibt es die [Personalliste](/auswertungen/personalliste) unter **Auswertungen**.
</Tip>

## Eine neue Person anlegen

Klicken Sie auf **Mitglied anlegen**. Wie das geht, steht unter [Mitglied anlegen](/personen/mitglied-anlegen).
