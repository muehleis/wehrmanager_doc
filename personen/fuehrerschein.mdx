Im Reiter **Führerschein** erfassen Sie, welche Fahrzeuge eine Person fahren darf und wann der Führerschein zuletzt kontrolliert wurde.

<Info>
  Wo finden Sie das? In der [Personenakte](/personen/personenakte) im Reiter **Führerschein**. Sie brauchen dafür das Recht **Führerschein**.
</Info>

## Status

Wählen Sie unter **Führerschein**, ob die Person einen Führerschein hat: **Unbekannt**, **Vorhanden**, **Entzogen** oder **Kein Führerschein**. Klicken Sie danach auf **Speichern**.

## Klassen

Hier tragen Sie die Führerscheinklassen ein, zum Beispiel B, C1 oder CE.

1. Wählen Sie die **Klasse**.
2. Tragen Sie ein, wann sie **erteilt** wurde und bis wann sie **gültig** ist. Bei Lkw-Klassen ist das Gültigkeitsdatum wichtig.
3. Wenn nötig, ergänzen Sie eine **Bemerkung**.
4. Klicken Sie auf **Hinzufügen**.

Ist das Datum unter **Gültig bis** bereits vorbei, wird es rot angezeigt.

## Führerscheinkontrollen

Viele Wehren kontrollieren regelmäßig, ob der Führerschein noch vorhanden ist. Tragen Sie dazu das Datum unter **Kontrolliert am** ein und klicken Sie auf **Erfassen**. Die Liste zeigt alle bisherigen Kontrollen, die neueste zuerst.

<Tip>
  Unter [Grundeinstellungen der Wehr](/einstellungen/wehr/grundeinstellungen) legen Sie fest, wie oft kontrolliert werden soll, zum Beispiel alle 6 Monate. Ist eine Kontrolle fällig, erscheint sie automatisch unter [Aufgaben](/aufgaben) und auf dem [Dashboard](/uebersicht-dashboard).
</Tip>

## Fahrzeuge

Hier halten Sie fest, auf welchen Fahrzeugen die Person eingewiesen ist.

1. Wählen Sie das **Fahrzeug**.
2. Tragen Sie ein, wann (**Eingewiesen am**) und von wem (**Eingewiesen von**) die Person eingewiesen wurde.
3. Setzen Sie den Haken bei **Fahrerlaubnis erteilt**, wenn die Person das Fahrzeug auch fahren darf. Ohne Haken gilt nur die Einweisung.
4. Klicken Sie auf **Hinzufügen**.

In der Liste steht dann **Fahrerlaubnis** (grün) oder **Nur Einweisung**.

Fahrzeuge legen Sie unter [Fahrzeuge](/einstellungen/wehr/fahrzeuge) an.
