Hier verwalten Sie, wer sich im Wehrmanager anmelden darf.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Userverwaltung**. Sie brauchen dafür das Recht **User-Verwaltung**.
</Info>

## Einen Benutzer anlegen

1. Klicken Sie auf **Benutzer anlegen**.
2. Tragen Sie **Vorname**, **Nachname** und einen **Benutzernamen** ein. Mit dem Benutzernamen meldet sich die Person an.
3. Tragen Sie die **E-Mail-Adresse** ein. Sie wird gebraucht, falls der Benutzer sein Passwort vergisst.
4. Wählen Sie die **Rolle**. Sie bestimmt, was der Benutzer sehen und ändern darf. Siehe [Rollen und Rechte](/einstellungen/rollen-und-rechte).
5. Vergeben Sie ein **Initialpasswort** und wiederholen Sie es.
6. Klicken Sie auf **Speichern**.

Teilen Sie dem Benutzer Benutzernamen und Initialpasswort mit. Bei der ersten Anmeldung muss er sich ein eigenes Passwort ausdenken.

## Die Benutzerliste

Mit dem Suchfeld finden Sie Benutzer nach Name, Benutzername oder E-Mail. Die Liste zeigt **Rolle** und **letzte Anmeldung**. Ein **Schild-Symbol** bedeutet, dass die Zwei-Faktor-Anmeldung aktiv ist. **Gesperrt** bedeutet, dass sich der Benutzer nicht anmelden kann.

## Aktionen

Klicken Sie in der Zeile eines Benutzers auf die **drei Punkte**:

| Aktion | Wann brauchen Sie das? |
| --- | --- |
| **Bearbeiten** | Name, E-Mail oder Rolle ändern. Wenn Sie ein neues Passwort eintragen, muss der Benutzer es bei der nächsten Anmeldung ändern. |
| **Passwort-Link senden** | Der Benutzer hat sein Passwort vergessen. Er bekommt eine E-Mail mit einem Link. Nur möglich, wenn eine E-Mail-Adresse hinterlegt ist. |
| **Zwei-Faktor zurücksetzen** | Der Benutzer hat sein Handy mit der Authenticator-App verloren. Danach muss er die App neu einrichten. |
| **Sperren** / **Entsperren** | Den Zugang vorübergehend sperren, zum Beispiel wenn jemand ein Amt abgibt. |
| **Löschen** | Den Benutzer endgültig entfernen. |

<Note>
  Ihren eigenen Zugang können Sie weder sperren noch löschen. So kann sich niemand versehentlich aussperren.
</Note>
