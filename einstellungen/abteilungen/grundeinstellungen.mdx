Hier bestimmen Sie, welche Angaben bei den Personen einer Abteilung erfasst werden.

<Info>
  Wo finden Sie das? Unter **Einstellungen › Abteilungen** beim gewünschten Eintrag auf das **Zahnrad** klicken. Oder im Einstellungsmenü links die Abteilung aufklappen und **Grundeinstellungen** wählen.
</Info>

## Bezeichnung

Unter **Bezeichnung** ändern Sie den Namen der Abteilung.

## Module

Schalten Sie die Module ein, die Sie in dieser Abteilung brauchen:

| Modul | Was damit möglich ist |
| --- | --- |
| **Beiträge** | Mitgliedsbeiträge berechnen, Mitgliedskonten, Lastschriften und Rechnungen. |
| **Jubiläen** | Jubiläen zur Mitgliedschaft in dieser Abteilung berechnen. |
| **Dienstgrade** | Dienstgrade bei Personen erfassen. |
| **Funktionen** | Funktionen und Wahlämter bei Personen erfassen. |
| **Ausbildung** | Lehrgänge, Qualifikationen und regelmäßige Nachweise erfassen. |
| **Abzeichen** | Verliehene Abzeichen und Ehrungen erfassen. |
| **Übungen** | Übungspläne, Anwesenheit und Übungsstunden. |

Ist ein Modul eingeschaltet, erscheint daneben ein Feld für die Bezeichnung. So können Sie das Modul umbenennen, zum Beispiel in „Lehrgänge“ statt „Ausbildung“. Klicken Sie danach auf **Speichern**.

<Note>
  Für jedes eingeschaltete Modul gibt es ein eigenes Recht je Abteilung. Wer was sehen darf, legen Sie unter [Rollen und Rechte](/einstellungen/rollen-und-rechte) fest.
</Note>

## Eigene Felder

Fehlt Ihnen eine Angabe, legen Sie ein eigenes Feld an, zum Beispiel „Spindnummer“, „Größe Einsatzjacke“ oder „Dienstzeit in anderer Wehr ab“.

1. Tragen Sie einen **Abschnitt** ein, zum Beispiel „Kleidung“. Felder mit gleichem Abschnitt werden zusammen angezeigt.
2. Tragen Sie den **Feldnamen** ein.
3. Wählen Sie die **Art**: **Text** oder **Datum**.
4. Klicken Sie auf **Hinzufügen**.

Die Felder erscheinen bei den Personen dieser Abteilung im Reiter **Weitere Angaben**. Die Reihenfolge ändern Sie per Ziehen.

<Tip>
  Ein eigenes Datumsfeld können Sie bei einem [Jubiläum](/einstellungen/jubilaeen) als Zählbeginn verwenden, zum Beispiel für Dienstzeiten in einer anderen Wehr.
</Tip>
