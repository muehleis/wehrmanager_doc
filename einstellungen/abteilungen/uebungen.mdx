Hier stellen Sie den Übungsbetrieb einer Abteilung ein.

<Info>
  Wo finden Sie das? Im Einstellungsmenü links unter **Abteilungen** die Abteilung aufklappen und **Übungen** wählen. Das Modul **Übungen** muss eingeschaltet sein.
</Info>

## Grundeinstellungen

- **Soll-Stunden pro Jahr**: wie viele Übungsstunden ein Mitglied pro Jahr leisten soll. **0** bedeutet keine Vorgabe.
- **QR-Code auf der Anwesenheitsliste**: Schalten Sie das ein, damit sich Mitglieder per Handy selbst als anwesend melden können. Siehe [Übungsteilnahme erfassen](/uebungsbetrieb/erfassung).
- **Hinweistext auf der Anwesenheitsliste**: zum Beispiel „Unterschreiben oder Code abfotografieren“.

Klicken Sie auf **Speichern**.

## Übungsgruppen

Mit Übungsgruppen teilen Sie eine Abteilung auf, zum Beispiel in „1. Zug“ und „2. Zug“ oder „Atemschutz“ und „Maschinisten“. Eine Übung kann dann nur für eine Gruppe gelten.

- Tragen Sie unter **Neue Übungsgruppe** den Namen ein und klicken Sie auf **Hinzufügen**.
- Mit dem **Stift** benennen Sie eine Gruppe um, mit dem **Papierkorb** löschen Sie sie.

Personen ordnen Sie in der Personenakte im Modul **Übungen** einer Gruppe zu. Siehe [Abteilungen und Module bei der Person](/personen/abteilungen-und-module).
