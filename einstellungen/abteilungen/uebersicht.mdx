Hier legen Sie die Abteilungen Ihrer Wehr an, zum Beispiel Einsatzabteilung, Jugendfeuerwehr, Kinderfeuerwehr, Alters- und Ehrenabteilung oder Förderverein.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Abteilungen**. Sie brauchen dafür das Recht **Abteilungs Einstellungen**.
</Info>

## Eine Abteilung anlegen

Tragen Sie unten unter **Neue Abteilung** den Namen ein und klicken Sie auf **Anlegen**.

## Die Liste

Für jede Abteilung sehen Sie, welche Module eingeschaltet sind. Inaktive Abteilungen tragen das Schild **Inaktiv**.

- Mit dem **Zahnrad** öffnen Sie die [Grundeinstellungen der Abteilung](/einstellungen/abteilungen/grundeinstellungen).
- Mit **Deaktivieren** blenden Sie eine Abteilung aus, die es nicht mehr gibt. Die Daten bleiben erhalten. Mit **Aktivieren** holen Sie sie zurück.
- Die Reihenfolge ändern Sie, indem Sie eine Abteilung am Symbol mit den **zwei Strichen** verschieben. In dieser Reihenfolge erscheinen die Abteilungen überall im Wehrmanager.

## Einstellungen je Abteilung

Im Einstellungsmenü links finden Sie unter **Abteilungen** jede Abteilung zum Aufklappen. Darin stehen die **Grundeinstellungen** und eine Seite für jedes eingeschaltete Modul:

- [Grundeinstellungen der Abteilung](/einstellungen/abteilungen/grundeinstellungen): Name, Module und eigene Felder
- [Funktionen](/einstellungen/abteilungen/funktionen)
- [Ausbildung und Abzeichen](/einstellungen/abteilungen/ausbildung-und-abzeichen)
- [Übungen](/einstellungen/abteilungen/uebungen)
- [Beiträge](/einstellungen/abteilungen/beitraege)

Dienstgrade gelten für die ganze Wehr. Sie legen sie unter [Dienstgrade](/einstellungen/wehr/dienstgrade) an.
