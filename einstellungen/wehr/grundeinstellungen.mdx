Hier stellen Sie die grundlegenden Angaben Ihrer Wehr ein.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Wehr**, dann links **Grundeinstellungen**. Sie brauchen dafür das Recht **Wehr Einstellungen**.
</Info>

## Name und Anschrift

Tragen Sie **Name**, **Namenszusatz**, **Anschrift**, **PLZ**, **Ort** und **Bundesland** ein. Die vollständige Anschrift wird zum Beispiel für die Rechnung des Abonnements gebraucht.

## Zwei-Faktor-Anmeldung für alle

Schalten Sie **Zwei-Faktor-Anmeldung für alle Benutzer verpflichtend** ein, wenn sich alle Benutzer besonders sicher anmelden sollen. Dann muss jeder Benutzer eine Authenticator-App oder einen Passkey einrichten, bevor er den Wehrmanager nutzen kann. Wie das geht, steht unter [Anmeldung und Sicherheit](/mein-konto/anmeldung-und-sicherheit).

<Tip>
  Im Wehrmanager stehen viele persönliche Daten. Die Zwei-Faktor-Anmeldung schützt sie, auch wenn ein Passwort einmal in falsche Hände gerät.
</Tip>

## Führerscheinkontrolle

Unter **Führerscheinkontrolle alle … Monate** legen Sie fest, wie oft die Führerscheine kontrolliert werden sollen. Liegt die letzte Kontrolle eines Mitglieds länger zurück, erscheint eine Aufgabe auf dem [Dashboard](/uebersicht-dashboard) und unter [Aufgaben](/aufgaben). Tragen Sie **0** ein, wenn Sie keine Erinnerung möchten.

Klicken Sie zum Schluss auf **Speichern**.
