Hier richten Sie Ihren Briefkopf ein und legen Vorlagen für Briefe an. Damit drucken Sie Einzelbriefe an eine Person oder Serienbriefe an viele Personen.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Wehr**, dann links **Briefe**.
</Info>

## Briefkopf

- **Absenderzeile**: die kleine Zeile über der Anschrift, die im Fensterumschlag zu sehen ist.
- **Fußzeile**: zum Beispiel Bankverbindung, Ansprechpartner oder Internetadresse. Zeilenumbrüche werden übernommen.
- **Logo**: Laden Sie ein PNG- oder JPG-Bild bis 2 MB hoch. Das Logo wird oben rechts gedruckt.

Klicken Sie auf **Speichern**.

## Eine Vorlage anlegen

1. Klicken Sie auf **Vorlage anlegen**.
2. Geben Sie eine **Bezeichnung** ein, zum Beispiel „Einladung JHV“.
3. Tragen Sie den **Betreff** ein.
4. Schreiben Sie den **Brieftext**. Sie können Text fett, kursiv oder unterstrichen schreiben, Überschriften und Aufzählungen verwenden.
5. Setzen Sie Platzhalter ein (siehe unten).
6. Klicken Sie auf **Speichern**.

Mit dem Symbol **Kopieren** erstellen Sie eine Kopie einer Vorlage, zum Beispiel für die Einladung im nächsten Jahr.

## Platzhalter

Platzhalter werden beim Drucken durch die Daten der Person ersetzt. Schreiben Sie sie mit geschweiften Klammern in den Text.

| Platzhalter | Wird ersetzt durch |
| --- | --- |
| `{briefanrede}` | z. B. „Sehr geehrter Herr Dr. Mustermann,“ |
| `{anrede}` | Herr / Frau / Familie |
| `{titel}` | Akademischer Titel |
| `{vorname}` | Vorname |
| `{nachname}` | Nachname |
| `{name}` | Titel, Vor- und Nachname |
| `{strasse}` | Straße und Hausnummer |
| `{plz}` | Postleitzahl |
| `{ort}` | Ort |
| `{geburtsdatum}` | Geburtsdatum |
| `{alter}` | Alter in Jahren |
| `{datum}` | Heutiges Datum |
| `{wehr}` | Name der Wehr |

## Briefe drucken

- **Einzelbrief**: In der [Personenakte](/personen/personenakte) oben rechts auf das **Briefumschlag-Symbol** klicken und eine Vorlage wählen.
- **Serienbrief**: In der [Personalliste](/auswertungen/personalliste) die Personen auswählen und auf **Serienbrief** klicken.
