Mit Übungsarten unterscheiden Sie verschiedene Arten von Übungsdiensten, zum Beispiel Theorie, Praxis oder Atemschutz.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Wehr**, dann links **Übungsarten**.
</Info>

## Eine Übungsart anlegen

1. Klicken Sie auf **Übungsart anlegen**.
2. Geben Sie eine **Bezeichnung** ein, zum Beispiel „Theorie“.
3. Geben Sie eine **Kurzform** mit höchstens drei Zeichen ein, zum Beispiel „T“.
4. Klicken Sie auf **Speichern**.

Die Kurzform erscheint im [Übungsplan](/uebungsbetrieb/uebungsplan) in der Spalte **Einheit**. Übungsarten wählen Sie beim Anlegen einer Übung und im [Themenkatalog](/uebungsbetrieb/themenkatalog).
