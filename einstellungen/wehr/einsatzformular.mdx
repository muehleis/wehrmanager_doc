Hier bestimmen Sie, wie der Einsatzbericht aussieht. Der Bericht ist in **Kategorien** gegliedert. Jede Kategorie hat **Abschnitte**, die als Reiter angezeigt werden. In jedem Abschnitt gibt es **Felder**.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Wehr**, dann links **Einsatzformular**.
</Info>

## Der schnelle Start: Standardformular

Ist noch kein Formular angelegt, bietet der Wehrmanager ein **Standardformular** an. Es enthält übliche Felder wie Alarmierung, Einsatzort, Fahrzeuge, Einsatzkräfte und Bericht.

1. Wählen Sie unter **Einsatzkräfte aus Abteilung** die Abteilung, deren Mitglieder als Einsatzkräfte auswählbar sein sollen, meist die Einsatzabteilung.
2. Klicken Sie auf **Standardformular anlegen**.
3. Passen Sie das Formular danach nach Ihren Wünschen an.

Alternativ beginnen Sie mit **Leere Kategorie** und bauen das Formular selbst auf.

## Das Formular anpassen

| Was möchten Sie tun? | So geht es |
| --- | --- |
| Neue Kategorie | **Kategorie anlegen** |
| Neuen Abschnitt (Reiter) | In der Kategorie auf **+ Abschnitt** klicken. |
| Neues Feld | Im Abschnitt auf **+ Feld** klicken. |
| Umbenennen oder bearbeiten | **Stift**-Symbol |
| Löschen | **Papierkorb**-Symbol |
| Reihenfolge ändern | Am Symbol mit den **zwei Strichen** ziehen. |

## Feldarten

Beim Anlegen eines Feldes wählen Sie die **Art**:

| Art | Wofür? |
| --- | --- |
| **Text (einzeilig)** | Kurze Angaben, zum Beispiel Einsatzort. |
| **Text (mehrzeilig)** | Längere Texte, zum Beispiel der Einsatzbericht. |
| **Zahl** | Zum Beispiel die Zahl der Verletzten. |
| **Datum** | Ein Datum. |
| **Uhrzeit** | Zum Beispiel Alarmzeit oder Einsatzende. |
| **Auswahlliste** | Feste Werte zur Auswahl, zum Beispiel Einsatzart. Tragen Sie unter **Auswahlwerte** einen Wert je Zeile ein. |
| **Mitglieder einer Abteilung** | Eine Liste zum Ankreuzen der Einsatzkräfte. Wählen Sie dazu die **Abteilung**. |
| **Fahrzeuge** | Eine Liste zum Ankreuzen der eingesetzten Fahrzeuge. |
| **Einsatznummer (automatisch)** | Zeigt die laufende Einsatznummer. |

Mit **In der Einsatzliste anzeigen** erscheint das Feld als eigene Spalte in der [Einsatzliste](/einsaetze). Das ist praktisch für Einsatzart oder Einsatzort.

<Note>
  Wenn Sie ein Feld löschen, bleiben die Angaben in bereits erfassten Einsätzen erhalten.
</Note>
