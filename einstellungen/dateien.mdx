In der Dateiablage bewahren Sie wichtige Dokumente der Wehr zentral auf, zum Beispiel die Satzung, Formulare oder Protokolle von Versammlungen.

<Info>
  Wo finden Sie das? Im Menü links unter **Einstellungen › Dateien**. Sie brauchen dafür das Recht **Dateien** (zum Hochladen **Lesen und Schreiben**).
</Info>

## Dateien hochladen

1. Klicken Sie auf **Dateien hochladen**.
2. Ziehen Sie die Dateien in das Feld oder klicken Sie hinein, um sie auszuwählen. Erlaubt sind PDF, Bilder, Word und Excel bis 20 MB je Datei. Sie können mehrere Dateien auf einmal hochladen.
3. Wählen Sie eine **Dateiart** und geben Sie bei Bedarf eine **Beschreibung** ein.
4. Klicken Sie auf **Hochladen**.

## Dateien finden und bearbeiten

- Über **Dateiart** filtern Sie die Liste.
- Klicken Sie auf den Dateinamen oder den **Pfeil nach unten**, um eine Datei zu öffnen oder herunterzuladen.
- Mit dem **Stift** ändern Sie Dateiname, Dateiart und Beschreibung.
- Mit dem **Papierkorb** löschen Sie eine Datei.

In der Liste sehen Sie auch, wann und von wem eine Datei hochgeladen wurde und wie groß sie ist.

<Note>
  Dateien zu einzelnen Personen legen Sie in der [Personenakte](/personen/personenakte) im Reiter **Dateien** ab. Dateiarten verwalten Sie unter [Dateiarten](/einstellungen/wehr/dateiarten).
</Note>
