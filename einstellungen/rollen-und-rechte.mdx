Mit Rollen legen Sie fest, was ein Benutzer sehen und ändern darf. Jeder Benutzer hat genau eine Rolle. Typische Rollen sind zum Beispiel „Wehrführung“, „Kassierer“, „Jugendwart“ oder „Ausbilder“.

<Info>
  Wo finden Sie das? Unter **Einstellungen › Userverwaltung** über die Schaltfläche **Rollen & Rechte**. Sie brauchen dafür das Recht **User-Verwaltung**.
</Info>

## Eine Rolle anlegen

1. Klicken Sie auf **Rolle anlegen**.
2. Geben Sie eine **Bezeichnung** ein.
3. Setzen Sie den Haken **Standard-Rolle für neue Benutzer**, wenn neue Benutzer diese Rolle automatisch bekommen sollen.
4. Stellen Sie die Rechte ein (siehe unten).
5. Klicken Sie auf **Speichern**.

Eine Rolle können Sie nur löschen, wenn ihr kein Benutzer mehr zugeordnet ist.

## Allgemeine Rechte

Die Rechte sind in Gruppen geordnet. Für jedes Recht wählen Sie **Ja** oder **Nein**, bei manchen Rechten **Lesen und Schreiben**, **Nur Lesen** oder **Nein**.

| Gruppe | Rechte |
| --- | --- |
| **Administration** | User-Verwaltung, Protokoll, Daten Export, Daten Import |
| **Allgemein** | Dashboard, Dateien, Einsätze, Jubiläen, Personallisten, Komfortsuche |
| **Finanzen** | Kasse und Bank, Kassenbericht |
| **Einstellungen** | Wehr Einstellungen, Abteilungs Einstellungen |
| **Personen** | Person anlegen, Passbild anzeigen, Zu Abteilung hinzufügen, Tags, Allgemeine Daten, Bankverbindungen, SEPA-Mandat, Führerschein, Jubiläen, Dateien |

## Rechte je Abteilung

Unter **Abteilungen** schalten Sie für jede Abteilung ein, ob die Rolle Zugriff hat. Ist der Zugriff eingeschaltet, wählen Sie für jedes Modul der Abteilung **Lesen und Schreiben**, **Nur Lesen** oder **Nein**.

<Note>
  Beispiel: Ein Jugendwart bekommt Zugriff nur auf die Jugendfeuerwehr. Dort darf er Ausbildung und Übungen bearbeiten, die Beiträge aber nur lesen. Personen der Einsatzabteilung sieht er nicht.
</Note>

<Tip>
  Geben Sie jeder Rolle nur die Rechte, die für die Aufgabe nötig sind. Das schützt die persönlichen Daten Ihrer Mitglieder.
</Tip>
