Jedes Mitglied hat je Abteilung ein Mitgliedskonto. Darauf stehen die Beiträge und Gebühren, die das Mitglied zahlen muss (Forderungen), und die Zahlungen, die eingegangen sind.

<Info>
  Wo finden Sie das? Im Menü links unter **Finanzen › Mitgliedskonten**. Das Modul **Beiträge** muss in der Abteilung eingeschaltet sein.
</Info>

## Die Liste

1. Wählen Sie die **Abteilung**.
2. Suchen Sie bei Bedarf nach **Name oder Mitgliedsnummer**.
3. Mit **Nur mit offenen Posten** sehen Sie nur Mitglieder, die noch etwas zahlen müssen.

Für jedes Mitglied sehen Sie die **Mahnstufe**, seit wie vielen Tagen eine Zahlung **überfällig** ist und den **offenen** Betrag. Unter der Liste steht die **Summe offen**.

Oben rechts drucken Sie die **Offenen Posten** der Abteilung aus oder laden sie als **CSV** herunter.

## Was Sie buchen können

Klicken Sie in der Zeile eines Mitglieds auf die **drei Punkte**:

| Aktion | Wann brauchen Sie das? |
| --- | --- |
| **Kontoauszug** | Alle Buchungen des Mitglieds mit Soll, Haben und offenem Betrag ansehen. |
| **Zahlung buchen** | Ein Mitglied hat bar oder per Überweisung bezahlt. Tragen Sie **Betrag**, **Buchungstag**, das Konto unter **Eingegangen auf** und den **Verwendungszweck** ein. |
| **Zusetzung** | Eine zusätzliche Forderung, zum Beispiel eine Gebühr oder ein Nachschlag. Wählen Sie eine **Kategorie**, **Betrag**, **Buchungstag**, **Fällig am** und den **Grund**. |
| **Absetzung** | Eine offene Forderung ganz oder teilweise erlassen. Wählen Sie die **offene Forderung**, den **Betrag** und geben Sie einen **Grund** an. |
| **Rücklastschrift** | Die Bank hat eine Lastschrift zurückgegeben. Wählen Sie die **zurückgegebene Lastschrift** und tragen Sie bei Bedarf **Bankgebühr** und **Bearbeitungsgebühr** ein. Optional können Sie die **Mahnstufe erhöhen** und das **SEPA-Mandat sperren**. |
| **Mahnstufe** | Die Mahnstufe von Hand setzen. |

<Note>
  Eine Zahlung gleicht immer zuerst die ältesten offenen Forderungen aus. Zahlt jemand mehr als offen ist, wird der Überschuss als Spende gebucht.
</Note>

Zahlungen werden automatisch auch in [Kasse und Bank](/finanzen/kasse-und-bank) gebucht. Welche Erlösart dabei verwendet wird, stellen Sie unter [Finanzen › Grundeinstellungen](/einstellungen/finanzen/grundeinstellungen) ein.

## Woher kommen die Forderungen?

Beiträge werden als Forderung gebucht, wenn Sie einen [Beitragseinzug](/finanzen/beitragseinzug) durchführen oder [Rechnungen](/finanzen/rechnungen) erstellen. Zusätzliche Forderungen buchen Sie über **Zusetzung**.
